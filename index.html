ViCaRe — VISSIM Calibrator and Reporter

Role: Inventor, Developer, Data Scientist, and Product Designer

Genetic Algorithm Optimization Simulation Calibration Multi-Metric Validation Engineer-Controlled Automation

ViCaRe is a professional automation software for VISSIM calibration, simulation result extraction, data processing, and Excel reporting. Built from more than three years of transportation research and calibration work, it reduces repetitive calibration time by replacing manual trial-and-error with structured search, validation, and reporting workflows.

  • Built more than 15,000 lines of Python code for VISSIM-COM automation, calibration logic, data processing, and reporting.
  • Designed calibration workflows using Genetic Algorithm and Hall-of-Fame logic.
  • Supported multi-scenario testing, multi-MoE validation, penalized error functions, dynamic mutation, and error tolerance.
  • Converted complex simulation outputs into structured, formatted, decision-ready Excel reports.
